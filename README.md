# Welcome to my CV project

## Project info
This project is a personal CV/portfolio application that highlights my professional background, technical skills, and software development projects. It is built to provide a clear and interactive overview of my experience, while also demonstrating my abilities in modern web development technologies, clean code practices, and UI/UX design.

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
